# Whether Fable 5.2 moves any house role, after Claude Code 2.1.321 (2026-11-09)

Research note for the Claude Code 2.1.321 addendum in `docs/handbook/sources/harness-survey.md`.
The price tables and the ladder paragraph in `docs/handbook/claude-code.md` change with this note;
no role's model or effort changes.

## Short answer

Every house role stays where it is: the ladder (Fable, Opus, Sonnet, Haiku), Opus as the default
session, Fable off subagents, and every roster pin. No house role runs on Fable, so no departure
note is made stale by this model. The overview page's guidance moved only its version number, from
Fable 5.1 to Fable 5.2. Local evidence (`research/model-tier/scripts/builder_tier.py`) was not run,
because no builder or other role runs on Fable.

## What changed

Claude Code 2.1.321 added `claude-fable-5-2` (also its alias): $8 input, $10 5m cache write, $16 1h
cache write, $0.20 cache read, and $40 output per Mtok; 1M context, 128K output, "Moderate"
latency (https://platform.claude.com/docs/en/about-claude/pricing,
https://platform.claude.com/docs/en/about-claude/models/overview). Fast mode is $16 input and $80
output, which is 2x, and Fable 5.1 is not in that table. Fable 5.1 keeps its $10, $12.50, $20,
$0.25, $50 row and is listed under "Legacy models (still available)". The API default effort is
`high` (overview page); the Claude Code default is `medium` ("Fable 5.2, Opus 5.5, Sonnet 5.5, and
Haiku 5.5 default to `medium`", https://code.claude.com/docs/en/model-config). Those are two
surfaces. Fetched 2026-11-09.

## Method

fetched 2026-11-09. The model-config and optimizing pages were read by search, not end to end. The
what's-new page for Fable 5.2 (https://platform.claude.com/docs/en/models/fable-5-2/whats-new-fable-5-2)
was not re-read by this session, so the implementation row below is marked. No verifier agent ran:
the decision is to change nothing, and each row rests on a quoted sentence or on the absence of one.
The system card PDF was over the fetch limit and was not read.

## Decision

No role moves. The ladder, the default session, Fable off subagents, and every roster pin stand,
and no `Re-measure:` issue is opened, since no departure measured an older model that this release
retires. If a role ever moves to Fable, run step 4 of
`.claude/skills/adapting-to-harness-updates/references/model-evaluation.md` first.
