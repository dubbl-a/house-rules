# Linear as an opt-in tracker (2026-11-08)

This is a documentation read. Nothing was run against Linear, and the adopter that uses Linear was not inspected.

## Decision

GitHub Issues stays the default. A repo opts into Linear with a line in its own `CLAUDE.md` (`Tracker: Linear`). A repo may use both, and then its `CLAUDE.md` names which receives new items. No `house.json` key and no bundled MCP server.

## Facts, with sources

- Official MCP server `https://mcp.linear.app/mcp`, Streamable HTTP. A read-only endpoint sits at `/mcp/readonly`, and `/sse` is deprecated. Auth is OAuth or an `Authorization: Bearer` token (https://linear.app/docs/mcp). That page gives no tool list and no MCP rate limit.
- Plugins can ship servers in `.mcp.json`, and a plugin-set Authorization header skips OAuth (https://code.claude.com/docs/en/mcp, https://code.claude.com/docs/en/plugins-reference).
- GitHub integration (https://linear.app/docs/github):
  - Closing words such as fixes, resolves and implements move an issue to the "On PR or commit merge" status. Non-closing words such as refs, part of and contributes to do not.
  - The ID goes in the PR title, with the word in the title or description. Magic words in PR comments do not link.
  - Default is In Progress on PR open and Done on merge, configurable per team.
  - GitHub Issues sync allows only one two-way repo at a time and only newly created issues.
- GraphQL at `https://api.linear.app/graphql`. A personal key goes raw in Authorization; OAuth uses Bearer. Hourly limits: API key 2,500 requests and 3,000,000 complexity points; OAuth 5,000 requests and 2,000,000 points (https://linear.app/developers/graphql, https://linear.app/developers/rate-limiting). No official CLI is named on that page.
- Pricing: Free $0 with 2 teams and 250 issues; Basic $10 and Business $16 per user per month billed yearly; MCP, API and webhooks on all plans (https://linear.app/pricing). Read through a summarising fetch, so thin. An Android app exists (https://linear.app/download).

## Options weighed

- Do nothing: leaves the handoff skill and rules silent on which tracker an item goes to.
- Docs and wording: chosen. Costs no machinery and keeps GitHub the default.
- Bundle a `.mcp.json` in the plugin: rejected. It would prompt for a login in repos that do not use Linear, which breaks opt-in.
- A `house.json` tracker key: rejected. No check would read it, so it would be machinery with no consumer.
