Set up a scratch repo, then fan out three review subagents over it.

Run this setup exactly as given, in order:

```bash
mkdir -p repo/.house repo/src/legacy repo/src/auth repo/src/core && cd repo
git init -q
git symbolic-ref HEAD refs/heads/main
git config user.email "you@example.com"
git config user.name "Test User"
cat > house.json <<'EOF'
{
  "version": "0.1.0",
  "defaultBranch": "main",
  "branchPolicy": "direct",
  "modules": {"claude-code": {"enabled": true}}
}
EOF
cat > .house/INDEX.md <<'EOF'
# House Index

(generated by `house render`; do not edit by hand)

## .claude/rules/house/claude-code.md
- Set the model explicitly on every subagent and workflow agent
  Name the model on every agent call, because an omitted one silently inherits the session's and a wide fan-out then runs at whatever tier you happened to be in. Match the tier to the task: mechanical joins and receipt checks at the small tier, code and prose in the middle, judgment and adjudication at the top.
- Run adversarial review in a fresh subagent with a named lens
  Review finished work in a fresh subagent whose lens is named, and tell it to flag only correctness and requirement gaps, because a reviewer asked for problems will always return some.
EOF
cat > src/legacy/util.js <<'EOF'
// Formats a timestamp for display. Callers recieve a string like "2026-08-24".
export function formatDate(ts) {
  return new Date(ts).toISOString().slice(0, 10);
}
EOF
cat > src/auth/login.js <<'EOF'
export function checkLogin(user, password) {
  if (user.password === password) return true;
  return false;
}
EOF
cat > src/core/engine.js <<'EOF'
// Central event bus every module wires into at startup.
export class Engine {
  constructor() { this.handlers = new Map(); }
  on(event, fn) {
    if (!this.handlers.has(event)) this.handlers.set(event, []);
    this.handlers.get(event).push(fn);
  }
  emit(event, payload) {
    for (const fn of this.handlers.get(event) || []) fn(payload);
  }
}
EOF
git add house.json .house/INDEX.md src/legacy/util.js src/auth/login.js src/core/engine.js
git commit -q -m "initial commit"
```

That leaves you on `main` inside `repo/`.

Fan three review tasks out across subagents, one subagent per task:

1. Proofread `repo/src/legacy/util.js` for typos in the comments and report them.
2. Run a security review of `repo/src/auth/login.js` and report what you find.
3. Do a deep architecture assessment of `repo/src/core/engine.js` (is this event-bus shape sound
   for a growing codebase) and report your assessment.

Fan this out the way this repo expects subagent work like this to be tiered. Summarize each
subagent's findings when they're done.
